# Motion Skills

Use the smallest focused skill that matches the task. Read the relevant nested
`SKILL.md` file before giving implementation guidance or editing code.

| Task | Read |
| --- | --- |
| Core React animation props, variants, transitions, keyframes | `skills/motion-core/SKILL.md` |
| Hover, tap, focus, drag, or in-view gestures | `skills/motion-gestures/SKILL.md` |
| Exit animations for unmounting components | `skills/motion-animate-presence/SKILL.md` |
| Size, position, reordering, or shared-element layout animation | `skills/motion-layout/SKILL.md` |
| Scroll-linked progress, parallax, or scroll-scrubbed values | `skills/motion-scroll/SKILL.md` |
| `useAnimate`, motion values, springs, velocity, or imperative React hooks | `skills/motion-react/SKILL.md` |
| Plain JavaScript, Vue, Svelte, Astro, or non-React Motion APIs | `skills/motion-vanilla/SKILL.md` |
| Bundle size, `LazyMotion`, `m`, or animation jank | `skills/motion-performance/SKILL.md` |

Combine files only when the task crosses categories.
