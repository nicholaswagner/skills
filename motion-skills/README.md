# motion-skills

Skills for [Motion](https://motion.dev/docs/react) (formerly Framer Motion) — the animation library for React and vanilla JS.

- **motion-core** — the `motion` component, `animate`/`variants`/`transition`, keyframes
- **motion-gestures** — `whileHover`, `whileTap`, `whileFocus`, `whileDrag`, `whileInView`, `drag`
- **motion-animate-presence** — exit animations on unmount
- **motion-layout** — `layout`, `layoutId`, `LayoutGroup`
- **motion-scroll** — `useScroll`, `useTransform`, scroll-linked effects
- **motion-react** — `useAnimate`, motion values (`useMotionValue`, `useSpring`, `useVelocity`, `useMotionValueEvent`)
- **motion-vanilla** — the standalone `animate()`/`hover()`/`press()`/`scroll()` API for non-React projects
- **motion-performance** — `LazyMotion`, `m` vs `motion`, transform-only animation

Modeled after this repo's `gsap-skills` plugin structure.
